# Suki Mini POS

ร้านสุกี้ขนาดเล็ก — ระบบ POS สำหรับพนักงานรับออร์เดอร์

## เริ่มใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที (เว็บ Static ไม่ต้องใช้ Backend)

## เอกสารระบบ

- `requirement.md` — ภาพรวมระบบ วัตถุประสงค์ ขอบเขต ผู้ใช้ และข้อจำกัด
- `userjourney.md` — ขั้นตอนการใช้งานของพนักงาน (Step / Action / System Response)
- `functional-requirement.md` — ข้อกำหนดเชิงหน้าที่ FR-01 ถึง FR-05
